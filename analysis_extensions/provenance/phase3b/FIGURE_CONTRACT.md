# Phase 3B figure contract

All three figures are candidate production artifacts pending the final evidence lock.

- Figure 1 is a framework schematic and contains no effect estimates.
- Figure 2 keeps the same-patient source comparison central: association is labeled separately from agreement, the original-scale Bland–Altman analysis remains primary, and the log-scale analysis is a concise post hoc sensitivity.
- Figure 3 is an SD-GV-only analytic-context landscape arranged by conceptual context family, never by effect size. MIMIC/INSPIRE are HR panels and eICU is an RR panel; no estimates are pooled.
- Patient-level Figure 2 source values remain controlled and are not included in the public release tier. Public release includes reproducible code and aggregate source data only.
- The R build reads locked result files and does not refit models or calculate new GV metrics.
